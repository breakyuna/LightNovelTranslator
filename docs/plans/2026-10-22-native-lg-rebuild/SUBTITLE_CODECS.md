## 边界与资产身份

`:core:formats` 的 `SubtitleDocument` 解析 SRT、LRC、ASS 和 SSA 的已解码字符串，提供有源定位的正文槽位与单语/双语渲染。它不连接工程数据库、不读写文件、不持有 Android Context、不发模型请求。

每个 `SubtitleSlotRef` 绑定整个已解码原稿的 UTF-8 SHA256、源 UTF-16 偏移及槽位源文 SHA256。引用不是列表序号；原稿中插入元数据也会改变文档绑定。未知/重复/跨原稿/伪造源文引用在返回结果前整体拒绝。槽位列表为不可变副本，正文和替换类没有自动输出内容的 toString。

这里的 SHA256 标识已解码文本，不冒充原始二进制资产身份。当前 `.lnt` v5 已扩展资产格式/槽位元数据；SubtitleFormatAdapter 将字幕核心接入 ProjectFormatService，NativeAppGraph 显式安装目录并接入工作台追加/按资产导出。非 TXT 文件使用真实格式身份，不以改后缀或登记为 TXT 绕过校验。各格式完整导入—修改—导出—重读及设备验收仍待补齐。

## 格式规则

| 格式 | 解析与写回 |
|---|---|
| SRT | 数字序号、合法起止时间和多行正文；源时间行及附加定位字段保留。单语空结果删除整个 cue，保留 cue 连续编号；双语保留源序号和原文，按开关去重。拒绝正文中会截断块的内部空行。BOM、源换行和未终止尾部有独立覆盖。 |
| LRC | 元数据及非正文行保留，行首连续时间标签（包括标签间空格和制表符）属于原结构并保留原字面间隔。正文中的方括号/尖括号逐字时间从暴露的正文中移除，标签两侧相邻非空白文字之间补一个空格，已有空白保留；没有行首方括号时间标签的行不提供翻译槽位；修改后的多行结果重复原时间标签组，禁止在目标正文注入时间标签。未改槽位保留源字面数据，首行 BOM 在展开时只保留一次。 |
| ASS / SSA | 仅处理 Events 段的 Dialogue，样式、注释和其余字段保留；Text 必须为最后且唯一的该字段，自定义 Format 按逗号边界定位，正文可包含逗号。未声明 Format 时校验标准十列及 ASS/SSA 首字段，段落切换重置布局。正文的 `\\N` 与真实换行双向转换，双语写在同一 Text 字段。 |

解析和渲染对齐审阅过的 LG `subtitle-text.ts`、`srt-format.ts`、`lrc-format.ts` 和 `ass-ssa-format.ts`。SRT 的损坏结构/时间检查比 LG 当前宽容读取更严格；未知或损坏布局拒绝，不能声称已完成所有历史文件兼容。

未修改区域使用源切片，未提交翻译的槽位回退源文。该核心不解释 ASS override 标签或 SRT 行内标记；其文本保护、术语、规则和完整翻译准备仍属于后续统一流水线，不能绕过它将这些槽位直接投入付费调用。

## 有界资源与失败

输入按 UTF-16 长度和严格 UTF-8 编码双重限制为 8 MiB，物理行/单元上限 100,000；单个目标字符串最多 65,536 个 UTF-16 code unit，最终输出最多 16 MiB。NUL 和损坏代理项拒绝。错误只包含分类和可选物理行号，不回显正文。

LRC 以迭代扫描读取重复时间标签，避免大前缀的递归正则增长；多行展开先以 Long 计算预计尺寸，再拼接，避免短译文加重复长前缀形成内存膨胀。ASCII 时间数字明确写为 `[0-9]`，不依赖平台 Unicode 正则差异。

这些是原型预算，不是已测量的设备容量。尚未验证 Android ICU、实际编码/字幕播放器、字体、渲染、SAF、真实工程保存重开及完整内存峰值。
